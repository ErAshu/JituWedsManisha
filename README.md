# Jitendra ❤ Manisha — Wedding Invitation

Open `index.html` in a browser (or host the folder on Netlify / GitHub Pages / Vercel).

## Add your files (exact names)
| File | What |
|---|---|
| `images/groom.jpg` | Groom photo (portrait, ~3:4) |
| `images/bride.jpg` | Bride photo (portrait, ~3:4) |
| `images/ganesh.png` | *(optional)* Ganesh ji image — transparent PNG. If missing, the built-in golden Ganesh art is used |
| `images/couple.jpg` | *(optional)* Preview image shown when the link is shared on WhatsApp |
| `music/wedding.mp3` | Background music (starts when the doors are opened) |

If a photo is missing, an elegant initial (J / M) is shown instead. If the music file is missing, the music button hides itself.
